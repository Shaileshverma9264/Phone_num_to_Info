# Mobile Lookup - React + Node.js

## Requirements

- Node.js 18+ (20+ recommended)
- VS Code

## Run backend

Open a terminal:

```bash
cd backend
npm install
copy .env.example .env
```

Edit `.env` and put your authorized API URL and API key.

Then:

```bash
npm run dev
```

Backend:
http://localhost:5000

## Run frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally:
http://localhost:5173

## Important

Do not put private API keys in the React frontend.

Only use personal/customer information when you have the legal authorization and appropriate privacy controls to process and disclose it.
